A=둘 다 / B=상황만 / C=취향만 / D=둘 다 아님. **취향을 따르는 것이 오답일 수 있는**

### ③ 대화 취약성 (Qwen3-VL-30B)

### ④ B/(B+C) 오답 체제 전환 — 가장 새로운 지표
오답 중 B(상황○ 취향✗) 비율: **오라클 7개 전부 ≤0.52 / 대화 8개 전부 ≥0.63, 겹침 0.**
→ 명시하면 취향 과적용(C오답), 추론시키면 규범 도피(B오답). **오답의 종류가 범주적으로 뒤집힘.**

## 2. 데이터 현황 — **v5b가 릴리즈여야 함**

| | v5 (구) | **v5b (신)** |
|---|---:|---:|
| plans | 2,566 | **2,560** |
| usable (4장) | 2,502 | **2,560** |
| eval skip | 64 | **0** |
| dialog 재등장 | 0.00% | **0.00%** (fallback 0) |
| 24유저 전원 시나리오 | 33 | **41** |
| 시나리오 최소 유저 | 10 | **14** |
| counterbalanced | — | 1,906 / 2,560 (74%) |

균형 이동 최대 **0.86pp** (한계 2pp). 검증 (a)~(f) 전부 PASS,
`verify_release.sh wacv_scenario_v5b` 비트 동일 재빌드 통과, mutation 48/48.

**v5b가 v5 리포트에 "미해결"로 적혀 있던 solid-baseline 순서 결함(cause 2)을 실제로 고칩니다** —
`plan_option_variant`가 배경을 `solid`로 덮어쓴 뒤의 셀을 `--image-manifest`가 검사하기 때문.

### 🔴 v5는 재현 불가능합니다 — 릴리즈를 v5b로 옮겨야 하는 결정적 이유
`--reserve-dialog-cells 3`은 **복원값이 아니라 추정값**입니다. 8/7 당시 라이브러리
스냅샷이 주석기에 의해 in-place 덮어써지고 커밋되지 않아, 어떤
(library × N × seed) 조합으로도 released `option_plans.jsonl`이 바이트 동일하게
재현되지 않습니다. `verify_release.sh`의 v5 라이브러리 핀 `72cc866…`도 지금 실패합니다.
→ **v5 수치 인용을 중단하고 v5b로 갈아타십시오.** v5b는 라이브러리·매니페스트가
모두 커밋된 상태에서 비트 동일 재빌드가 검증됐습니다.

### 남은 판단 1건 — reservation을 끌 것인가
`--avoid-option-cells strict`(대화 측)만으로 recurrence 0%가 보장되고,
reservation은 **84 plan(2,644→2,560)을 비용으로 지불**합니다. 게다가 `_CURRENT_UID`가
`assign_ab_values.dof()`·`plan_option_variant`에서만 세팅되어 **예약 1,296쌍 중 549쌍이
누출**됩니다(v5b 기준).
→ **`--reserve-dialog-cells 0`으로 한 번 돌려 `recur_fallbacks`가 0으로 유지되는지 확인.**
유지되면 예약을 끄고 84 plan 회수, 아니면 3 유지. 이 테스트 전에는 결정 금지.

### 참고 — 미실체화 셀의 정체
`images_manifest.json`은 "available 전체"가 아니라 *(당시 plan이 쓰는 셀) ∩ available*로
생성됨. 8/7 plan 재생성 후 매니페스트를 갱신하지 않아 16셀이 누락됐던 것.
그 16셀 실체화로 14 plan 회수. 나머지 50은 라이브러리에 **없는** 17셀
(`screen_partial`, 예: `cardigan|solid`가 13색 중 7색만 스크리닝) 때문이며,
신규 수집·주석 없이는 도달 불가 → `--image-manifest`가 제거.

## 3. 최대 리스크 / 미해결

3. **텍스트 쌍둥이 대화 미평가** ← 최고 가성비. `dlg__U*__text.json` 이미 생성됨. Modality Gap 확정
4. 통계 없음 (cluster bootstrap: user > dialog > query > plan)
5. 위치 편향 2건: Qwen2.5-7B dialog B슬롯 43.4%, PersonaVLM 44.6%
6. 런 미완결: Qwen2.5-72B, gemma-3-27b dialog(timeout 496)
7. 지각 vs 통합 미분리 (SAM3 3-way 모듈러 베이스라인 = future work로 결정)

## 4. 서술 지침 (rebuttal 없음 → Limitations가 방어의 전부)
- **헤드라인은 간섭**, Figure 1은 직교성. "we introduce a benchmark"로 시작하면 Weak Accept에서 멈춤
- **"선호 정확도는 선호 추론이 아니라 지각+지시준수를 잰다"를 Results 앞에 명시**
- **sycophancy와 구분**: 저쪽은 *틀린 믿음*에 굴복, 여기는 *정당한 취향*의 과적용 → "preference over-application"
- 규모 방어: **PCogAlignBench(ACL'25)가 20명** → 24명은 관행 범위
- Limitations 6항목, 가장 아픈 것(인간 천장) 맨 앞. Scope/Limitation/Defect를 섞지 말 것
- 마지막 문장: *"Each of these is stated with the measurement that bounds it; none is repaired silently."*

## 5. 관련 문헌 (포지셔닝)
- **PrefEval** (ICLR'25 Oral) — 선호 준수가 문맥 거리로 붕괴. 텍스트. 가장 중요한 비교 대상
- **PCogAlign** (ACL'25) — VLM 개인화 정렬, Role-Set, 20명. 개인화가 *목표*, 우리는 *유보 대상*
- **PersonaVLM** (CVPR'26 Highlight, `ClareNie/PersonaVLM`, base=Qwen2.5-VL) — 유일한 대화형 학습 개인화 모델
- **CoViP** (`Yeongtak/CoViP-Qwen3-VL-8B-GSPO`, base=Qwen3-VL-8B) — 문맥 회상 vs 신규 이미지 trade-off를 이미 전제
- **Visual Haystacks**(ICLR'25) / **CoMemo**(ICML'25) / **V2PE**(ICCV'25) — 시각 장문맥·위치 편향
- **TAME**(KDD'26) — 무학습 장문맥 개인화. 동일 기반 위 비교 가능
- 멀티모달 개인화 *정렬* 범주는 **3편뿐**(PCogAlign/PersonaVLM/CoViP) → Related Work 논거
